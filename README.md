## Overview

HST-ZeroDefault is an ethical, lightweight framework for building safe, autonomous systems. It emphasizes:
- **Do No Harm**: Blocks malicious patterns.
- **User Autonomy**: Requires explicit consent.
- **Transparency**: Logs actions with timestamps.
- **Privacy by Design**: Anonymizes sensitive data.
- **Fairness**: Rate-limits to prevent abuse.
